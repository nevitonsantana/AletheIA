# Domain Governance Usage examples

This folder contains source-backed reviews of how delivered domain governance packs are used before AletheIA adds more packs, enforcement, scanners or automation.

- [`s34-domain-governance-usage-review.json`](s34-domain-governance-usage-review.json) — reviews the S28 AI Agent Security and S29 Web App Security minimum packs, confirms they are usable as advisory guidance, and keeps enforcement/new-pack expansion deferred.
- [`s35-domain-governance-usage-evidence-capture.json`](s35-domain-governance-usage-evidence-capture.json) — defines how future real usage evidence should be captured without treating this template as real usage.
