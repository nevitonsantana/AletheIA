# S16 cognitive and documentation closure examples

These fixtures demonstrate the proportional S16 extension:

- `low-risk-docs.json` — a reviewed documentation-only change can proceed;
- `stale-documentation.json` — a required stale surface must be updated before closure;
- `high-risk-human-review.json` — understanding cannot replace specialist review for a high-risk technical change.

They are closure records, not new Work Slice states or automated policy decisions.
