## Current operating posture

| Area | Current state | What it means |
|---|---|---|
| Governance | Delivered 1.x baseline | Work framing, gates, decisions, validation, closure, and continuity are the core operating model. |
| Adaptive Skills | Complementary and separate | AletheIA governs the Work Slice; Adaptive Skills provides portable methods. Neither project owns the other. |
| Security packs | Delivered as guidance | The packs are manual/advisory. Real usage evidence requires a real Work Slice, not a template or synthetic example. |
| Observability | Read-only baseline | Known records can be projected with provenance; a projection does not pass gates or infer missing values. |
| Documentation | Public Blume site plus governed pilot report template | Publication remains a separate, manual approval and smoke-test action. Pilot reports are evidence records, not adoption badges or runtime automation. |

## Explicit limits

:::warning[Not active or not authorized]
The current baseline does not include Runtime 2.0 implementation, automatic collectors, new dashboards, policy engines, scanners, technical enforcement, automatic routing, autonomous learning, memory writeback, Adaptive Skills mutation, people scoring, or comparative performance metrics.
:::

The absence of a metric is represented as `unavailable`, not a guessed number. Five heterogeneous Work Observatory records are not a stable comparison group, so no success rate, ranking, or productivity claim is admissible.
